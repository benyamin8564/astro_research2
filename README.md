# Astro Research

## APK download
After pushing this project to GitHub, open **Actions → Android APK Build → the latest run**. At the bottom of the run page, the **Artifacts** section will contain `astro-research-apk`. Download it to get `astro-research.apk`.

IMPORTANT: Upload the project files including `.github/workflows/blank.yml`. Do not create a different blank workflow manually. The workflow must show the name **Android APK Build** in GitHub Actions.
